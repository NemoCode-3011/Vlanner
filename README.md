# Vlanner

A static landing-page concept for an AI hiring product, built with HTML and CSS.

**Live website:** https://vlanner.vercel.app/

## Built with

- HTML
- CSS
- Custom fonts and image assets

## Run locally

No package installation is required. Open `index.html` in a browser, or use a local static server for a closer preview of a deployed website.

## Project scope

This repository contains the landing page and its presentation assets. It does not include an application backend or AI hiring functionality.
